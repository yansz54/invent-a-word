**showergument** — *The imaginary argument you rehearse in the shower and always win.*

One new English word for a thing everyone has felt and no one has named:
the argument you only ever win under running water.

## Run

```sh
node main.ts
```

Writes `entry.txt` (80 characters, one line) to `/output`
(or `$MAKEFUN_OUTPUT_DIR`). Deterministic: no clock, no network,
no randomness — two runs produce byte-identical output.
